# John Idowu / ChaseInTech

Founder and lead engineer of [ChaseOS](https://chaseos.ai/), and the builder behind [Opus Vela](https://opusvela.com/) and [MarginFlip](https://marginflip.com/). I design and deliver agent infrastructure, Windows applications and cloud products, taking ownership from system architecture through integration, testing and release.

My work connects the parts that make software useful beyond a demo: persistent memory and data, authenticated services, tool permissions, editable workflows, billing, packaging and recovery. Across the portfolio, that includes a local-first AI workspace, private dictation and creative tools, reseller operations software and event-driven market research.

## Engineering focus

- **Agent infrastructure:** project memory and knowledge graphs, source provenance, bounded MCP tools, runtime permission checks and durable review/audit records.
- **Product engineering:** authenticated React interfaces and Python/TypeScript services, SQL data models, REST APIs and webhooks, exact money/FX handling, Clerk and Stripe Checkout.
- **Windows software:** Electron and C# integrations for capture, dictation and text insertion; editable video/design workflows with typed, revision-checked agent operations.
- **Data and delivery:** FastAPI, PostgreSQL, Redis Streams and SQLite; Cloudflare Workers, Pages, D1, R2 and KV; automated tests, CI and Windows release packaging. Docker/WSL2 services support the development environment.
