# John Idowu / ChaseInTech

I’m John, founder of [ChaseOS](https://chaseos.ai/) and a Computer Science (Artificial Intelligence) undergraduate at the University of Greenwich. I build Python and TypeScript applications, APIs and agent tools, from requirements and architecture through testing and release.

Current products include [Opus Vela](https://opusvela.com/) for Windows dictation and creative tools, and [MarginFlip](https://marginflip.com/) for reseller inventory and profit workflows. My Linux/WSL2 work uses Docker development environments with persistent PostgreSQL, Redis and Qdrant services.
